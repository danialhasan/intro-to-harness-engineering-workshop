The same semantic rule can require mechanisms across several harness surfaces.

POLICIES ↔ KNOBS ↔ PROJECTIONSThe mapping is many-to-many. That is why the design space becomes combinatorial.

Projection is not a single box where a policy goes. It is the set of executable mechanisms that collectively make a semantic rule true. Progressive capability disclosure can combine prompt context, tool filtering, controller state, and permissions. Evidence-based completion can combine a verifier, state, a stop hook, and trace persistence. The mapping is many-to-many.
