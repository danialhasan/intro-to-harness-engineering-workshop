What is
harness engineering?

The practice of designing the system around a model so it can pursue a specific outcome reliably.

What it seesContext and observations

What it can doTools and authority

What persistsState

What evidence returnsFeedback and verification

When stopping is justifiedCompletion rules

The model is one component of the agent system.

A model provides capability. The harness turns that capability into an operating system for a task. It assembles context, exposes tools and authority, carries state, returns observations and feedback, invokes verification, and decides whether to continue, stop, or escalate. These controls can change the trajectory, but a harness change does not automatically improve the outcome. [Sources] research/FORMAL_FOUNDATIONS.md; research/HARNESS_CODE_PROVENANCE.md.
