The same semantic rule can require mechanisms across several harness surfaces.

POLICIES ↔ KNOBS ↔ PROJECTIONSThe mapping is many-to-many. That is why the design space becomes combinatorial.

Projection is not a single box where a policy goes. It is the set of executable mechanisms that collectively make a semantic rule true. Progressive capability disclosure can combine prompt context, tool filtering, controller state, and permissions. Evidence-based completion can combine a verifier, state, a stop hook, and trace persistence. The mapping is many-to-many. This is the causal discipline. Hold the task, model, runtime, authority, evaluator, and budget fixed. Change one harness mechanism. Compare the traces, artifacts, and evaluator results. One pair can illustrate a mechanism. Repeated pairs support a claim about expected effect. More tasks are needed for a claim about generalization. The live workshop uses a local deterministic evaluator with the same separation of concerns.
