# Repository router for Codex

This repository contains a public lecture and a synthetic hands-on workshop.

When a participant asks to start or resume the hands-on workshop:

1. Work from `workshop/`.
2. Read and follow `workshop/AGENTS.md` and `workshop/WORKSHOP_AGENT.md`.
3. Use `workshop/README.md` as the participant procedure.
4. Do not change the fixed Taskset, model, Runtime, evaluator, or controls.

After the experiment card is complete, surface the optional continuation menu
in `workshop/prompts/README.md`. Do not start a follow-on path until the
participant chooses it. Never read private traces from this public clone.

For repository maintenance, preserve the tested workshop path. Do not present
an author simulation as an attendee decision or a completed participant run.
