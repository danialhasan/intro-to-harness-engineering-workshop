# Verification and stopping Taskset

- Task ID: `verification-stopping/v1`
- Failure pattern: ongoing supervision, premature stopping, and incorrect
  completion claims.
- Synthetic scenario: a release helper creates a ready marker without checking
  the required evidence.
- Fixed evidence: missing checks, failed checks, artifact identity, and the
  complete ready path.

This Taskset contains no participant data and does not reproduce a survey
response. See the parent [Taskset library](../README.md) for validation and
privacy rules.
